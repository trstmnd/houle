# Agents

Les consignes de travail de ce dépôt sont dans **`CLAUDE.md`**, et valent pour tout agent,
quel que soit l'outil (Claude Code, opencode, autre). Lis-le en entier, puis `SPEC.md`.

Ordre de lecture : `CLAUDE.md` (comment travailler) puis `SPEC.md` (quoi construire).
`LATER.md` est la liste de ce qu'on ne code pas. `attic/` est l'ancienne version 2D, abandonnée.

Avant chaque push : `sh check.sh`. Rouge = rien ne se déploie.
